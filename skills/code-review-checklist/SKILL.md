# Чек-лист ревью диффа

Перед показом диффа проверь каждый пункт:

- [ ] Дифф читается: нет отладочного мусора, закомментированного кода, личных заметок
- [ ] Имена/форматы следуют стилю соседнего кода
- [ ] Обработаны ошибки по краям (сеть, файлы, ввод) — нет «голых» исключений
- [ ] Нет секретов и ключей (envVar, а не константы)
- [ ] Тесты/проверки зелёные (прогон в копии)
- [ ] Новые файлы — по месту (структура проекта), без дублей
- [ ] Удаления намеренные и объяснённые

## Формат замечаний

Каждое замечание — к строке диффа: `файл:строка — что не так и как исправить`.
Пока непройдены все пункты — дифф не показывается.
