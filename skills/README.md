# Шаблоны скиллов dirigo v2 (V2-5.4)
#
# Скилл — папка в skills/<имя>/ с SKILL.md (инструкция агенту) и опционально
# scripts/ (zero-dep bun-скрипты) + references/. Демон регистрирует каталог
# skills/ как библиотеку: агент получает список скиллов в промпте сессии
# (solo-режим), выбранный скилл копируется в копию проекта.
#
# Структура:
#   skills/
#     <name>/
#       SKILL.md          — обязательно: фронтматтер (name/description) + инструкции
#       scripts/          — опционально: исполняемые проверки/утилиты (bun)
#       references/       — опционально: дополнительные материалы по требованию
#
# Планировщик (V2-6.x): `bun run scripts/skills-list.ts` печатает список скиллов.
