# TDD: красный → зелёный → рефакторинг

1. **Красный**: напити падающий тест на поведение (не на реализацию).
2. **Зелёный**: минимальный код, который тест проходит. Ничего лишнего.
3. **Рефакторинг**: улучши структуру — тесты остаются зелёными.
4. Повтори для следующего поведения.

## Правила

- Один тест — одно поведение. Имя теста = предложение о поведении.
- Если тест «красный» по инфраструктуре — сначала почини инфраструктуру, не поведение.
- Рефакторинг без теста = баг в ожидании.

## Проверка

Запусти проверки проекта (движок сам определит: package.json/Makefile/pytest/cargo/just).
Все зелёные — показывай дифф. Красные — исправляй, не показывай.
